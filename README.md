## Step 1 — Prerequisites (one-time setup)

### 1a. On your Jenkins server
```bash
# Install Ansible
pip3 install ansible

# Install AWS CLI (needed if Jenkins triggers S3 downloads directly)
pip3 install awscli

# Verify
ansible --version
aws --version
```

### 1b. On all three MySQL target nodes
- OS: RHEL 8 / CentOS 8 / Rocky 8 (glibc 2.28 required for Percona tarballs)
- The `mysql` OS user will be created by Ansible — **do not pre-create it**
- SSH from Jenkins → nodes must work (key-based, no password)
- The target nodes need outbound access to your S3 bucket (via IAM role or credentials)

### 1c. Upload binaries to S3
Upload the following tarballs to your S3 bucket before running the pipeline:

| Local file | S3 key |
|---|---|
| `Percona-Server-8.0.42-33-Linux.x86_64.glibc2.28.tar.gz` | `s3://YOUR-BUCKET/mysql/` |
| `percona-xtrabackup-8.0.35-34-Linux-x86_64.glibc2.28.tar.gz` | `s3://YOUR-BUCKET/xtrabackup/` |
| `mysql-shell-8.0.43-linux-glibc2.28-x86-64bit.tar.gz` | `s3://YOUR-BUCKET/mysql-shell/` |
| `percona-toolkit-3.7.0-2_x86_64.tar.gz` | `s3://YOUR-BUCKET/percona-toolkit/` |
| `proxysql-2.7.3-Linux-x86_64.glibc2.28.tar.gz` | `s3://YOUR-BUCKET/proxysql/` |

```bash
aws s3 cp Percona-Server-8.0.42-33-Linux.x86_64.glibc2.28.tar.gz \
    s3://your-org-mysql-binaries/mysql/
# repeat for all 5 tarballs
```

> **Change `your-org-mysql-binaries`** in `Jenkinsfile` line `S3_BASE = "s3://your-org-mysql-binaries"` to match your bucket name.

## Step 3 — Create Jenkins Credentials

In Jenkins → **Manage Jenkins → Credentials → (global)**:

| Kind | ID | What it holds |
|---|---|---|
| SSH Username with private key | `mysql-ssh-key` | Private key Jenkins uses to SSH into the DB nodes |
| Secret text | `mysql-sudo-pass` | sudo/become password on the target nodes |

> For passwords that go into `vars.yml` (root password, cluster admin password), use **Ansible Vault** (see Step 5) rather than plain text.

---

## Step 4 — Create the Jenkins Pipeline Job

1. Jenkins → **New Item** → name it `mysql-innodb-cluster` → select **Pipeline** → OK
2. Under **Pipeline**:
   - Definition: **Pipeline script from SCM**
   - SCM: **Git**
   - Repository URL: your GitHub/GitLab URL
   - Branch: `*/main`
   - Script Path: `Jenkinsfile`
3. Click **Save**

---

## Step 5 — Ansible Vault for Passwords (Recommended)

Create a vault file to store secrets:
```bash
ansible-vault create ansible/inventory/vault.yml
```
Add inside:
```yaml
vault_mysql_super_password: "YourRootPassword123!"
vault_cluster_admin_password: "ClusterAdmin456!"
vault_s3_backup_bucket: "your-org-mysql-backups"
```

The `vars.yml` template references `{{ vault_mysql_super_password }}` and `{{ vault_cluster_admin_password }}` — these stay encrypted at rest.

Store the vault password in Jenkins as a **Secret text** credential (ID: `ansible-vault-pass`) and add to the pipeline:
```groovy
withCredentials([string(credentialsId: 'ansible-vault-pass', variable: 'VAULT_PASS')]) {
    sh "echo $VAULT_PASS > /tmp/.vault_pass"
    sh "ansible-playbook ... --vault-password-file /tmp/.vault_pass"
    sh "rm -f /tmp/.vault_pass"
}
```

## Step 6 — Run the Pipeline

1. Jenkins → `mysql-innodb-cluster` → **Build with Parameters**
2. Fill in:

| Parameter | Example |
|---|---|
| NODE1_IP | `10.0.1.11` |
| NODE2_IP | `10.0.1.12` |
| NODE3_IP | `10.0.1.13` |
| MYSQL_VERSION | `8.0` |
| MYSQL_MINOR | `8.0.42-33` |
| MYSQL_PORT | `3306` |
| MYSQL_GR_PORT | `33106` |
| MYSQL_DATA_DIR | `/dbdata/mysql` |
| APP_NAME | `myapp` |
| ENV_NAME | `poc` |
| DC_NAME | `dc1` |
| DRY_RUN | ✅ (start with this!) |
| ANSIBLE_TAGS | `all` |

3. Click **Build** — review the dry-run output
4. Re-run with **DRY_RUN = false** to deploy for real

---

## Step 7 — Verify

After the pipeline completes:
```bash
# SSH into the primary node
ssh mysql@NODE1_IP

# Check cluster status
/dbdata/mysql/myapp/poc/binaries/innodbcluster-8.0.42-33/bin/mysqlsh \
  clusteradmin@NODE1_IP:3306 \
  --js -e "print(dba.getCluster().status())"
```

Expected: all 3 nodes showing `"status": "ONLINE"`, one as `PRIMARY`, two as `SECONDARY`.

## Customisation Reference

| What you want to change | Where to change it |
|---|---|
| MySQL port | Jenkins parameter `MYSQL_PORT` |
| Data directory | Jenkins parameter `MYSQL_DATA_DIR` |
| Add a new MySQL version | Add entry to `s3Map` in Jenkinsfile + upload tarball to S3 |
| Tune InnoDB buffer pool | Edit `mysql_innodb_buffer_pool_size` in `vars.yml` or Jenkinsfile |
| Add a 4th node | Add IP to `[secondary]` in the inventory generation code in Jenkinsfile |
| Change backup S3 bucket | Set `s3_backup_bucket` variable in vault.yml |
